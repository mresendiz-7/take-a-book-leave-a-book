# The Little Book Trail

A single-page static website about take-a-book, leave-a-book stands around Ellensburg, WA (IT-248 Website Design Project).

## Files
- `index.html`: page structure
- `style.css`: styling (geocache field guide + cottagecore)
- `index-v1.html` + `style-v1.css`: backup of version 1 (illustrated book spines, no photos)
- `images/`: original SVG illustrations (library house, trail map, flower vase, bookshelf, favicon)

All image paths are relative (`images/...`), so keep this folder structure when you upload to GitHub.

Locations and coordinates are mock data for a class project.

Book photos are free Unsplash photos (Unsplash License), loaded directly from images.unsplash.com. Photographers are credited in the footer.
